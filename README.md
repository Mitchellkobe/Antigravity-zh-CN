## 💡 为什么推出这个增强版？（解决原版核心痛点）

在直接使用原版汉化包时，许多普通用户与网友普遍遇到了以下门槛和报错：
1. **强制依赖 Node.js 环境**：双击运行 `.bat` 脚本时直接提示：
   `'node' 不是内部或外部命令，错误: 汉化注入失败，请确认是否已安装 Node.js`。普通用户并不具备前端开发环境，安装配置 Node.js 极为繁琐。
2. **强制联网拉取依赖 (npx)**：原版解包与打包强制调用 `npx -y @electron/asar` 实时联网下载，国内网络环境极易出现网络超时、卡死或报错失败。
3. **缺少直观友好的图形界面**：只有简单的黑窗口控制台，普通用户操作容易感到无措。

针对以上问题，本项目进行了**彻底的底层重构与体验优化**，打造了真正面向全体普通用户的 **“零门槛、开箱即用”** 汉化方案！

## 🔥 核心优化与技术升级

### 1. 彻底免安装 Node.js（智能引擎自适应）
* Antigravity 客户端底层基于 Electron 架构，其自身内部就已经自带了完整的 Node 运行环境。
* 本项目对注入引擎进行了深度改造，当检测到用户电脑未安装 Node.js 时，会**自动利用 Antigravity 内置引擎驱动运行**。
* **用户无需配置 PATH，无需安装任何几十兆的额外运行库，绿色纯净，开箱即用！**

### 2. 纯原生离线 ASAR 解包与打包（0 网络依赖，秒级注入）
* 彻底剔除了脆弱的 `npx` 联网下载机制，重写为**纯原生内存级 ASAR 解析与重打包算法**。
* 不需联网、不挑网络环境、无任何外部依赖，解包注入与完整校验重打包**全过程 1 秒内瞬间完成**。

### 3. 全新高颜值现代 GUI 管理器（`Antigravity汉化工具.exe`）
* 基于 WPF 开发的独立桌面程序，采用现代深色 Fluent UI 风格设计与高清矢量 DPI 缩放。
* **一目了然的状态卡片**：自动定位客户端路径、实时检测运行状态与当前汉化状态。
* **一键傻瓜式操作**：
  * ⚡ **一键安装中文汉化**（支持自由切换简体中文 / 繁體中文，支持保留原英文品牌名/隐藏/汉化为“反重力”）
  * 🔄 **一键还原官方英文原版**（自动创建与管理官方原版备份，随时无损一键还原）
  * 🚀 **启动 Antigravity**（汉化完成后直接在工具内一键拉起客户端体验）
* **实时黑客风控制台面板**：详细展示每一步注入与校验日志，支持一键清空与一键复制日志。

### 4. 同步修复原版批处理脚本
* 同步修复了目录下的 `双击安装中文汉化.bat`、`双击安装繁体中文.bat`、`双击卸载还原官方英文.bat`。即使喜欢使用传统命令行的用户，双击也不会再报 `node` 缺失错误。

## 📥 极速使用指南

1. 前往本仓库右侧的 **[Releases](../../releases)** 页面，下载最新的 `Antigravity_中文汉化包_v2.0_开箱即用版.zip`。
2. 将压缩包解压到本地任意文件夹（请勿在压缩包内直接运行）。
3. 退出正在运行的 Antigravity 客户端，双击打开 **`Antigravity汉化工具.exe`**。
4. 勾选您需要的语言版本，点击 **【⚡ 一键安装中文汉化】**。
5. 提示完成后，点击 **【🚀 启动 Antigravity】** 即可畅享全中文界面！

## ❓ 常见问题 (FAQ)

#### Q: 后续 Antigravity 官方发布版本更新后，汉化会失效吗？
> **A:** 官方推送更新后，由于会覆盖原有的客户端资源，软件会暂时自动恢复为英文原版（不会崩溃或报错）。  
> **应对方式极简**：您完全不需要等待新版补丁，只需重新打开本工具，再次点击一次 **【一键安装中文汉化】**，1 秒钟即可再次恢复全中文界面！

#### Q: 会影响 AI 接收到的指令或提示词吗？
> **A:** 完全不会。本汉化仅作用于客户端前端界面的 DOM 视觉渲染层，大模型底层获取到的依旧是纯正英文指令，绝不影响模型生成质量。
