========================================================================
             Antigravity 智能中文汉化包 (v2.0 增强开箱即用版)
========================================================================

【特点亮点】
 1. 彻底免装 Node.js / Python 等任何开发环境，纯净绿色，开箱即用！
 2. 纯原生离线 ASAR 极速解包与重打包，不连外网、不卡死、0依赖秒级注入。
 3. 拥有高颜值现代化图形管理界面，支持一键安装、一键还原、一键启动。
 4. 完美支持简体中文、繁體中文，支持自定义左上角品牌名称显示。

------------------------------------------------------------------------
【使用方法（推荐图形界面）】
------------------------------------------------------------------------
 1. 将本压缩包全部解压到一个文件夹中（请勿直接在压缩包内运行）。
 2. 双击打开【Antigravity汉化工具.exe】。
    （如遇系统安全提示，请点击“允许”或右键选择“以管理员身份运行”）
 3. 程序会自动检测 Antigravity 安装路径。
 4. 选择您喜欢的语言（简体中文 / 繁體中文）和品牌名称显示方式。
 5. 点击【⚡ 一键安装中文汉化】按钮。
 6. 提示安装成功后，点击【🚀 启动 Antigravity】即可开始使用！

------------------------------------------------------------------------
【备用命令行方式】
------------------------------------------------------------------------
 如果您喜欢命令行脚本，也可以直接双击：
 - 【双击安装中文汉化.bat】 -> 安装简体中文
 - 【双击安装繁体中文.bat】 -> 安装繁體中文
 - 【双击卸载还原官方英文.bat】 -> 随时恢复官方原版英文

------------------------------------------------------------------------
【注意事项】
------------------------------------------------------------------------
 * 汉化前建议关闭正在运行的 Antigravity 客户端（图形工具也会自动帮您处理）。
 * 首次安装汉化时，工具会自动生成官方原版备份（app.asar.bak），随时可一键还原。
 * 如后续 Antigravity 官方发布新版本更新，只需再次运行本工具点击安装汉化即可。

祝您使用愉快！
